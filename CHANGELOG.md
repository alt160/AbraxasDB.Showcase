# Changelog

## 1.0.0

- Initial standalone Showcase repository and Windows x64 portable ZIP release.
- Targets .NET 10 and consumes the public AbraxasDB 1.0.1 package.
- Includes OSS lessons and complete copyable programs; commercial examples display an edition notice.
- Requires the installed .NET 10 Windows Desktop Runtime x64 and WebView2 Evergreen Runtime.
